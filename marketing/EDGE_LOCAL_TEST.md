# Edge 完全本地激活测试

测试日期：2026-10-17。

## 使用

在项目根目录启动本地服务（保持 VPN 连接即可）：

```sh
npx wrangler dev --local --ip 127.0.0.1 --port 8788
```

当前会话已启动服务。Ctrl+C 可停止。启动依赖首次可能需要下载；激活请求本身仅访问本机。

Edge 的 `edge://extensions/` 已停用原版，启用 `dist/edge-local-test/` 中的「BOSS海投（本地测试版）」。测试版 ID：`jbnmacenbjhjibbdkbfdjeaeedlmkeef`。

测试卡密保存在 `private/local-test-keys.json` 的 `data[0]`（权限600，Git忽略），已绑定当前 Edge 测试扩展。其他浏览器不能复用此卡密；需要另行生成本地卡密。管理令牌在 `.dev.vars`，未输出、未提交。

测试副本的 API 为 `http://127.0.0.1:8788/api`，已去除生产激活域名权限及打开购买网站行为。正式源码和上架 ZIP 未被此项配置修改。

## 验证结果

- 本地健康接口：200、ok。
- UI 输入格式有效但不存在的卡密：提示「激活卡密无效」。
- UI 输入本地生成卡密：提示「激活成功」。
- 刷新后：显示「高级功能已激活」。
- 设置中：招聘者状态、附件简历、继续搜索、排除猎头控件已解锁；未启动投递。
- 停止服务并确认8788不可达后刷新：仍显示已激活，离线凭证有效。
- 重启服务：管理查询显示同一条卡密记录，activated=true，KV持久化通过。

本测试仅验证本地激活；BOSS页面仍联网，未验证大陆无VPN可达性，未发送消息或简历。

## 恢复正式版

停用本地测试版，再启用原版并刷新 BOSS 页面。两者使用不同扩展存储，本地测试激活不授予正式版高级权限。请勿将本地测试目录上传商店。
